# Flyby directory agent guide

Read [README.md](README.md) and the canonical
[milestone workflow](../milestone-workflow.md) before acting in this tree.

Keep only `README.md` and this guide at the flyby root. Put every newly noticed
raw report directly under `inbox/`, then return to the authorized task without
listing, reading, searching, deduplicating, or investigating existing reports.

Read and triage reports only after explicit milestone acceptance and before
the next milestone alignment. During that authorized triage, also classify any
misplaced report found outside `inbox/`; do not silently treat its location as
proof that it was already promoted.
